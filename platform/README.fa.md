# پلتفرم — خلاصه فارسی

این پوشه بازیِ اختصاصی ساخته‌شده روی موتور Voxelize (ریشه‌ی همین مخزن) است:
یک دنیای وُکسلیِ دائمی، چندنفره و تحت وب با Survival و اقتصاد بازیکن‌محور.

موتور (ریشه‌ی مخزن) عمومی و بی‌خبر از بازی می‌ماند؛ هرچه مخصوص بازی است در
`platform/` قرار دارد و وابستگی فقط یک‌طرفه است (بازی ← موتور).

## اصول غیرقابل‌مذاکره

۱. **اقتدار سرور:** کلاینت فقط «قصد» می‌فرستد؛ سرور تصمیم می‌گیرد.
۲. **پول فقط از طریق لجر:** عدد صحیح، دوطرفه، اتمیک، Idempotent، غیرقابل‌ویرایش.
۳. **محتوا داده است:** بلاک، آیتم، دستور ساخت، بایوم و… در JSON تعریف می‌شوند.
۴. **جداییِ Creative و Survival:** ارز و آیتم‌های این دو هرگز مخلوط نمی‌شوند.
۵. **هویت مستقل:** هیچ Asset یا نامی از بازی‌های دیگر کپی نمی‌شود.

## اجرا

```sh
cd platform
cp .env.example .env     # رمزها را پر کنید (مثلاً با openssl rand -hex 32)
docker compose up --build
```

## گام‌های بعدی

نقشه‌ی راه کامل در `docs/ROADMAP.md` است. فاز بعدی: کلاینت وب (ورود، دریافت
بلیت، اتصال، کنترل بازیکن) و استخراج/ساخت معتبرشده در سرور همراه با Inventory.
